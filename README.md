# LumosCam — Tela de Galeria

Projeto de faculdade: front-end (HTML, CSS e JavaScript).

## Estrutura

```
lumoscam-galeria/
├── index.html   → estrutura da página
├── style.css    → estilos complementares (a base de cores/espaçamento vem do Tailwind)
└── script.js    → dados das fotos e lógica de filtro por categoria
```

## Tecnologias

- HTML5
- CSS3
- Tailwind CSS (via CDN)
- JavaScript puro (vanilla JS) — usado só para o filtro de categorias, sem framework



## Funcionalidades

- Header com identidade visual do app (LumosCam)
- Filtros por categoria (Tudo, Retratos, Paisagens, Noturno, Macro, Vintage)
  com rolagem horizontal
- Grade de fotos que se atualiza conforme a categoria selecionada
- Cada foto recebe um filtro de cor (brilho, contraste, saturação) diferente
  de acordo com a categoria, simulando o processamento automático do app
- Barra de navegação inferior (Câmera, Filtros, Comunidade, Galeria)
